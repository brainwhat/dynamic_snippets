# Референсы стиля

Три TikTok-видео, которые пользователь прислал как образец (3 ноября 2026). Файлы не переименованы. Цифры сняты командой `./snip ref <часть имени>`.

| файл (часть имени) | размер | длина | фон | первый кадр | смен фона в секунду | что ещё |
|---|---|---|---|---|---|---|
| `tiktok_ligamentxv…` | 1920×1080, 30 fps | 24.7 с | тёмно-синий 37, 61, 93 | чёрный | 2.3 | слово набирается по слогам: НАП, НАПЛЕ, НАПЛЕВАТЬ |
| `киса подай мне знак…` | 1920×1080, 30 fps | 21.3 с | красный 155, 31, 30 | чёрный | 1.2 | по центру белая строка курсивом, она набирает всю спетую строку |
| `по просьбе @Karen…` | 1280×720, 30 fps | 15.1 с | индиго 54, 60, 104 | цветной | 2.1 | слова появляются целиком, без слогов |

Общее у всех трёх:

- на экране одно слово, иногда короткая группа («ГДЕ ТО», «У НАС», «С ТОБОЙ», «О ЛЮБВИ?»);
- жирный гротеск капсом растянут по высоте: буквы занимают 0.93-0.97 высоты кадра, ширина обычная, поэтому буквы очень узкие;
- слово стоит по центру и держится до следующего, пустых кадров нет;
- на каждом новом слове фон меняется: цвет с чёрными буквами или чёрный с буквами этого цвета;
- никаких движений, масштабов и переходов, только жёсткие смены кадра под слог;
- «Й» выглядит как «И», потому что бреве уходит за верхний край кадра;
- запятые на большом тексте не ставятся, точка и вопрос в конце фразы бывают («СУКИ.», «ЗНАК.», «ХОЧЕШЬ?»).

Шрифт в референсах определить точно не удалось. У него острые «Л» и «А», «Д» треугольником и «Г» со скошенной перекладиной. Ближе всего из свободных шрифтов Jost 700 (`fonts/Jost-wght.ttf`), он и стоит в `styles/styles.json`. Курсив во втором референсе каллиграфический, «д» и «г» рукописные. Сейчас вместо него Palatino Italic из macOS.

Стили `navy`, `red`, `indigo` в `styles/styles.json` повторяют эти три видео. Новый референс кладётся сюда же, потом `./snip ref <часть имени>` печатает готовый стиль для `styles/styles.json`.

## Референс 4: `Tongue twister…` (прислан 17 ноября 2026)

Другой вид, в движке это стиль `tongue` со своим модулем `engine/tongue.py`. Числа сняты по кадрам.

| | |
|---|---|
| размер | 1440×1080 (4:3), 60 fps, 14.2 с |
| цвета | кремовый 244, 220, 180 / 243, 207, 154 и бордовый 62, 3, 0 / 79, 4, 1; первый кадр бордовый |
| мерцание | фон и буквы каждые 2 кадра (1/30 с) переключаются между двумя оттенками своего цвета, отсюда «28 смен в секунду» в `./snip ref` |
| большое слово | узкий гротеск капсом, края букв неровные, будто вырезаны ножницами, штрихи чуть наклонены; высота 0.44-0.49 кадра (не 0.93, как в референсах 1-3), по центру, ширина по слову |

Текст из двух строк («I want it…», «wanna get you in a tongue twister…») идёт по кругу четыре раза, и каждый раз в новой подаче. Фон чередуется кремовый/бордовый на каждом слове во всех подачах.

1. **Большие слова** (0-2.3 с): I, WANT, IT по одному, как в референсах 1-3, но буквы ниже.
2. **Маленькая строка набирается по словам** (2.3-4 с): I, I want, I want it по центру мелким жирным скруглённым шрифтом в строчных (примерно 0.04 высоты кадра). Повтор строки в скобках «(I want it)».
3. **Сдвиг панелей**: новое слово выезжает снизу на панели другого цвета, старая панель уходит вверх. Сдвиг не плавный, 2-3 скачка за 0.1-0.2 с, граница панелей неровная, как рваная бумага. Так же строка «tied up in a tongue twister» висит полоской у края кадра и набирается по словам, пока большие слова сменяются над ней.
4. **Мелкие слова контуром**: «get», «greasy» тонким контуром, «grea» заливкой, набор по слогам: grea, greasy.
5. **Курсив поверх большого слова** (9.8-11.6 с): большое слово капсом приглушено (на креме цвет 204, 174, 132, то есть 15-20% бордового; на бордовом тонкий контур), поверх него то же слово рукописным курсивом строчными, цвет переднего плана.
6. **Приглушённое слово плюс строка** (11.6-14.2 с): большое приглушённое слово сзади, поверх по центру мелкая строка набирается по словам: tied, tied up, … tied up in a tongue twister.

Всё это сделано как вид `tongue` (README.md, раздел «Вид tongue»): кадр 4:3, мерцание, неровные края, подачи `big`, `push`, `line`, `small`, `script`, `ghost`, `strip`. Шрифты с кириллицей взяты из того, что есть на Mac: DIN Condensed Bold, Unbounded Black (мелкий текст, выбор пользователя), Snell Roundhand. Подпись чужого аккаунта внизу кадра не переносится.
