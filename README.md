# dynamic_snippets

Кинетическая типографика 16:9 для треков пользователя: одно слово на весь кадр. Эталоны стиля лежат в `references/`, их разбор в [references/README.md](references/README.md).

Как выглядит видео:
- на экране одно слово или короткая группа («В ДРЕБЕЗГИ», «С ЭТИМ»), жирный гротеск Jost 700 капсом, растянутый по высоте на 93% кадра;
- слово набирается по слогам точно под голос: НАП, НАПЛЕ, НАПЛЕВАТЬ;
- на каждой новой карточке фон меняется: цвет стиля с чёрными буквами или чёрный с буквами цвета стиля;
- карточка держится до следующей, пустых кадров нет, движения нет, только жёсткие смены;
- 1920×1080, 60 fps.

Дополнительно умеет: белую строку курсивом по центру (стиль `red`, как во втором референсе), мигание фоном на каждой доле, пока висит карточка, титульные карточки в заданную секунду. Отдельный вид `tongue` по четвёртому референсу описан ниже в разделе «Вид tongue».

Что уже есть, смотри в [INDEX.md](INDEX.md): треки с разметкой частей (что снято, что свободно), все видео и стили. Обновляется командой `./snip index`.

## Новое видео за 7 шагов

Все команды запускаются из этой папки. Список команд: `./snip --help`.

1. **Трек.** Если трек уже есть в `tracks/`, переходи к шагу 2.
   - Трек есть в `../lyrics_snippets/tracks/`: `./snip import-track <id>`. Команда копирует звук, стемы и слова (`words.json`) за секунду (клоны APFS, место на диске не тратится).
   - Нового трека нет нигде: `./snip add-track "/path/to/song.wav" <id> --title="Название" --artist="…" --lang=ru`. Это Demucs и слова по голосу (GigaAM для `--lang=ru`, иначе Whisper), примерно 1-2 минуты.

   Потом заполни в `tracks/<id>/track.json` поля `sections`, `bpm` и `downbeat` (секунда начала любого такта). Сетка нужна для `--bars` и для мигания на долях.
2. **Кусок.** `./snip map <track>` показывает строки из `words.json`, уровень голоса через каждые 0.5 с и паузы. `./snip edge <track> <секунда>` показывает уровень через каждые 0.1 с вокруг точки. `./snip bars <track>` печатает начала тактов.
   - Режь по тактам: видео крутится по кругу в TikTok, конец должен стыковаться с началом на сильной доле.
   - Хвост последнего слова не обрезай, лучше удлинить кусок на долю.
3. **Видео.** `./snip new <vid> <track> --bars=0-16 --style=pink --part="хук 1"` (или секунды вместо `--bars`: `./snip new <vid> <track> 2.01 34.09`).
   - `vid` заканчивается числом (`dora2`), оно попадёт в имя файла «dynamic 2».
   - Стили смотри в `./snip styles`. Новый цвет добавляется в `styles/styles.json`.
   - Если на краях куска слышна соседняя строка, допиши в `audio` переключение на `inst` (см. «Формат видео»).
4. **Текст.** Запиши текст в `videos/lyrics/<vid>.txt`, одна спетая строка на строку. Разметка описана ниже.
5. **Выравнивание.** `./snip align <vid>` ставит время каждой буквы текста по голосу (MMS_FA), примерно минута. После любой правки текста запускай заново, иначе рендер откажется работать.
6. **Проверка.**
   - `./snip check <vid>`: файлы, текст, слишком короткие кадры, слова, которые пришлось сжать по ширине.
   - `./snip plan <vid>`: каждая смена экрана со временем видео, временем песни, длиной и цветом. Здесь видно, на какой слог что появляется.
   - `./snip sheet <vid>`: все состояния экрана на одной картинке `cache/stills/<vid>_sheet.jpg`. Это самый быстрый способ проверить видео целиком.
   - `./snip still <vid> --t=10`: один кадр в `cache/stills/`.
   - `./snip render <vid> --draft`: черновик 960×540 30 fps в `cache/drafts/` за несколько секунд.
7. **Рендер.** `./snip render <vid> [<vid2> …]` создаёт в `output/<Название>/` три файла:
   - видео `<Название> - dynamic N 16x9.mp4`;
   - обложку `… обложка.jpg` (титульная карточка, если она есть, иначе кадр на трети видео или секунда из `cover`);
   - копию для телефона `phone/<vid>_phone.mp4`.

   Рендер 30 секунд видео идёт около минуты, файл весит 2-4 МБ. Под конец выполни `./snip index`.

## Разметка текста

| запись | что получится |
|---|---|
| `мы отвисаем, как челюсти` | каждое слово своя карточка, слова набираются по слогам |
| `где_то` | одна карточка «ГДЕ ТО», каждое слово всё равно набирается по слогам |
| `в дребезги`, `с этим` | однобуквенные предлоги в, с, к, у, о сами склеиваются со следующим словом |
| `за\|еба\|ли` | свои шаги набора вместо автоматических слогов |
| `рокстар\|` | слово целиком, без набора по слогам |
| `рокстар*` | пока карточка висит после последнего слога, фон мигает на каждой доле (нужны `bpm` и `downbeat`) |
| `*бать{ебать}` | звёздочка внутри слова или в начале остаётся на экране (цензура пользователя); мигание включает только `*` в конце; в `{}` то, что спето |
| `@2.0108 как_дора*` | строка с `@` в начале: не спетая карточка в эту секунду песни, в выравнивании не участвует; в одной строке можно несколько `@секунда карточка` |
| `7{семь}` | на экране «7», выравнивается как «семь» |
| `(у-е)` | выкрик в скобках не показывается |
| `# …` | комментарий |
| `[script] строка` | подача строки в виде `tongue` (см. «Вид tongue»); в других стилях пропускается |

Автоматически:
- запятые, кавычки и двоеточия на большом тексте не печатаются, «—» и «–» становятся «-»; в строке курсивом знаки остаются;
- карточка короче 0.12 с склеивается со следующей (`MIN_CARD`): «и ничего» превращается в «И НИЧЕГО», если «и» спето слишком быстро;
- шаг набора короче 0.07 с показывается вместе со следующим (`MIN_STEP`);
- слог появляется на 0.02 с раньше звука (`LEAD`); раньше заметно хуже, чем позже, но 20 мс глаз не видит.

Слоги режутся так, как в референсах: одна согласная между гласными уходит в следующий слог, из двух и больше первая остаётся в предыдущем (НАП-ЛЕ-ВАТЬ, ПОД-РУ-ГИ, РОК-СТАР, ДРЕ-БЕЗ-ГИ, ЗА-Е-БА-ЛИ); «ь» и «ъ» остаются при своей согласной. В английских словах соседние гласные считаются одной, конечная «e» после согласной немая.

## Правила пользователя (обязательно)

Перенесены из `lyrics_snippets`, там их сформулировал пользователь.

- **В этой папке пользователь делает видео только из своих треков.** Чей трек, не проверять и не спрашивать, текст ставится целиком.
- **Текст только от пользователя или из его файлов.** Если текст снят распознаванием (GigaAM или Whisper), перечисли пользователю слова, в которых не уверен.
- **Никогда «—» на экране**, только «-». Движок сам заменяет длинное и короткое тире.
- **Без подписей** выкриков в скобках «(У-е)» и распевов «У-у», «Я-я-я», «О-о-о». В звуке они остаются, в тексте их нет.
- **Края куска.** Начало и конец не должны содержать звук соседних строк: переключай на `inst` или режь на паузе. Последнее слово не обрезать, лучше удлинить кусок на долю.
- **Никаких сгенерированных ИИ картинок и видео.** Здесь только текст, так что это касается новых идей оформления.
- **Новый вид** (не стиль из `references/`) сначала показывается одним кадром (`./snip still`), рендер только после «одобряю».
- **Имя артиста:** «feelthsame» (th, без e).
- **Не длиннее 20 секунд, минимум 2 видео на трек, лучше 3 и больше** (2026-11-04). Длинные части режь на несколько видео по тактам, чтобы каждое крутилось по кругу. Несколько треков в одном сообщении делаются по очереди, каждый до рендера.
- **Трек и текст получены, значит сразу делать видео, без вопросов.** Идти по 7 шагам до рендера включительно. Если id трека не назван, взять его из названия (латиницей, коротко). Если не назван стиль, взять цвет с обложки трека или один из стилей референсов. Всё, что решено без пользователя, перечислить в конце ответа. Исключение одно: сомнительный текст (слова, снятые распознаванием) перечисляется в ответе, а не угадывается.

## Стили `styles/styles.json`

`_base` общий для всех: шрифт `font` и его толщина `weight` (100-900), высота заглавной буквы `cap` (доля высоты кадра), ширина `width` (ширина слова `width_word` «НАПЛЕВАТЬ», делённая на высоту буквы; 1.264 снято с первого референса), предельная ширина `maxw` (доля кадра, длиннее слово сжимается), цвет `dark` (второй фон, по умолчанию чёрный), шрифт строки курсивом `sub_font`, `sub_index`, `sub_size`.

Стиль задаёт `accent` (RGB), может задать свой `dark` и `grad` (список цветов: буквы на тёмных карточках переливаются слева направо), `first` (`accent` или `dark`: каким фоном начинается первая карточка), `subs` (строка курсивом) и `note`. Любой ключ `_base` можно переопределить в стиле или в самом видео через `"tweak": {…}`.

## Вид tongue (референс 4)

Стиль с `"look": "tongue"` рисуется модулем `engine/tongue.py`, а не обычной карточкой. Образец: `dora4` (хук «Как дора», такты 0-8), лист всех подач: `cache/stills/tongue_modes.jpg`.

- Кадр 4:3 (`--size=4x3`, 1440×1080), как в референсе; 16x9 тоже работает.
- Большие слова узким DIN Condensed Bold (macOS, с кириллицей), высота буквы 0.46 кадра (`big_cap`), ширина подогнана по «WANT» из референса (`big_width`). Края неровные, штрихи чуть наклонены: маска букв сдвигается плавным шумом. Слово длиннее 0.9 кадра (`big_maxw`) сначала сжимается до 85% (`big_squeeze`), дальше становится ниже. `./snip check` пишет о словах ниже 70%: такую карточку лучше разбить.
- Пока слово на экране, оно медленно растягивается или сужается по ширине (до 4%), через карточку в разные стороны.
- Мерцание: 30 раз в секунду (`flicker_hz`) фон и буквы переключаются на второй оттенок (`accent2`, `dark2`). Поэтому рендер рисует каждый кадр заново (черновик 16 с за 3 секунды).
- Каждая строка текста получает подачу: `[подача]` в начале строки, иначе по кругу из `modes` стиля (титульные карточки `@` идут как `big`).

| подача | что на экране |
|---|---|
| `big` | большое слово, слоги набираются как обычно |
| `push` | то же, но новая карточка въезжает снизу на своей панели в 2-3 скачка (`push_steps`: секунда от начала карточки и где верх панели, доля кадра), граница рваная |
| `line` | вся спетая строка мелким Unbounded Black (`fonts/`, `small_font`, `line_size`), растёт по словам и слогам |
| `small` | только текущее слово, мелко (`word_size`); на бордовых карточках контуром |
| `script` | большое слово приглушено (на кремовом заливкой, `ghost` = доля бордового, на бордовом тонким контуром), поверх то же слово рукописным Snell Roundhand (macOS, `script_size`) |
| `ghost` | приглушённое большое слово, поверх растущая строка мелким шрифтом |
| `strip` | большое слово чуть выше, внизу полоса другого цвета с рваным краем, в ней растущая строка; размер шрифта подбирается по всей строке, чтобы она влезла в одну линию (до 60% от `line_size`) |

В референсе одни и те же строки идут по кругу, каждый раз в новой подаче. Для своих треков подачи лучше ставить так, чтобы соседние строки отличались, а `push` и `strip` не шли подряд.

## Паспорт трека `tracks/<id>/track.json`

```json
{"title": "Как дора", "artist": "feelthsame", "lang": "ru", "bpm": 119.72, "downbeat": 2.0108,
 "source": "откуда взят звук", "duration": 130.0,
 "sections": [{"name": "хук 1 (такты 0-16)", "start": 2.011, "end": 34.086}, …],
 "notes": "где Whisper врёт, неподтверждённые слова, сетка", "videos": ["dora1"]}
```

`title` попадает в имена файлов. `bpm` и `downbeat` (секунда начала такта 0) нужны для `./snip bars`, `--bars` и мигания `*`.

## Формат видео `videos/videos.json`

```json
"dora1": {
  "track": "kakdora", "part": "хук 1", "start": 2.0108, "end": 34.0856,
  "style": "pink", "size": "16x9", "fps": 60,
  "audio": [[2.0108, "mix"], [32.98, "inst"]], "fade": 0.03,
  "onsets": {"5": 3.6, "5.1": 3.75}, "status": "delivered"}
```

- `start`/`end`: секунды трека. Для петли лучше ровно по тактам (`--bars`).
- `style`: имя из `styles/styles.json`; `tweak`: свои значения поверх стиля, например `{"accent": [20, 90, 60]}` или `{"subs": true}`.
- `size`: `16x9` (1920×1080, как референсы 1-3), `4x3` (1440×1080, референс 4), `9x16`, `1x1`, `4x5`. В вертикальном кадре длинные слова сильнее сжимаются по ширине.
- `audio`: с какой секунды трека что звучит: `mix` (оригинал), `inst` (без голоса), `voc` (только голос). Между переключениями 30 мс. Стемы подгоняются по громкости к миксу на этом куске. Первый элемент всегда начинается в `start`.
- `fade`: затухание в конце, по умолчанию 0.03 с (видео крутится по кругу).
- `onsets`: ручное время слога в секундах песни. Ключ `"5"` значит первый слог слова 5, `"5.1"` второй слог слова 5. Слова считаются с 0 по всем спетым словам текста подряд, титульные карточки `@` не считаются.
- `cover`: секунда видео для обложки, если титульной карточки нет.
- `status`: `draft`, потом `rendered` (ставит рендер), потом `delivered` (ставь руками, когда отправил пользователю).

## Как работают тайминги

1. `./snip align` прогоняет MMS_FA (torchaudio) по отделённому голосу всего куска с известным текстом. Получается время каждой буквы.
2. Слово режется на слоги. Слог начинается со времени своей первой буквы.
3. Это время подтягивается к ближайшему всплеску голоса (spectral flux 300-4000 Гц) в окне от 80 мс раньше до 40 мс позже (`SNAP`). Ошибка уходит в сторону «чуть раньше»: текст, появившийся раньше звука на 50-100 мс, не заметен, а опоздание на 45 мс уже видно.
4. `onsets` перекрывают всё.
5. Затем `LEAD`, `MIN_STEP`, `MIN_CARD` (см. «Разметка текста»).

Слабые места:
- Тянущиеся гласные без согласной между ними («мы-ы о-отвисаем»): MMS может ошибиться на 0.1-0.2 с. `./snip align` печатает слова, которые сильно разошлись с `words.json`. Проверь их в `./snip plan` и закрепи в `onsets`.
- Уровень вероятности MMS на пении почти всегда низкий, на него не смотри.

## Новый стиль по новому референсу

1. Положи видео в `references/`.
2. `./snip ref <часть имени файла>` печатает размер, цвет фона, каким фоном начинается, как часто меняется фон, какую долю высоты занимают буквы, есть ли строка курсивом, и готовый кусок JSON для `styles/styles.json`.
3. Добавь стиль под своим именем, допиши строку в таблицу `references/README.md`.
4. Если у нового референса заметно другой шрифт или другая ширина букв, поменяй в стиле `font`, `weight`, `width`, `cap` и проверь на `./snip still`.

Его времена слов сдвинуты на 0.1 с раньше (`LEAD` в `engine/transcribe_gigaam.py`), чтобы совпадать с Whisper, под который настроены старые видео. Старые треки сняты Whisper'ом, их `words.json` не пересчитывались.
