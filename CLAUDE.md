# Для ИИ-агентов

Прочитай README.md (как сделать новое видео, разметка текста, правила пользователя, форматы) и INDEX.md (что уже есть: треки, видео, стили). Образцы стиля лежат в references/, их разбор в references/README.md. Всё делается через ./snip; ./snip --help.

Когда пользователь присылает трек и текст, делай видео сразу, до рендера, без вопросов (правило в README.md, «Правила пользователя»).

**Сколько и какой длины (правило пользователя от 2026-11-04):** каждое видео не длиннее 20 секунд; на каждый трек минимум 2 видео, лучше 3 и больше. Длинный куплет или хук режь на несколько видео по тактам. Если пользователь прислал несколько треков, делай их по очереди: закончил один (рендер включительно), переходи к следующему.
